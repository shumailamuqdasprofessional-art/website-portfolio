# Skin Edits — Portfolio Website

A responsive portfolio website for **Skin Edits**: skin retouching, photo and video editing.

## Sections
- Hero with a draggable **before / after** comparison slider
- Services
- Portfolio gallery with category filters and a lightbox
- 4-step process
- Pricing packages
- Contact form (opens the visitor's email app)

## Run it
No build step is needed. Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

and visit http://localhost:8000.

## Customize
- **Colors and fonts:** edit the variables at the top of `css/styles.css`
- **Photos:** see `images/README.md`
- **Email:** replace `hello@example.com` in `index.html` and `js/script.js`
- **Prices and text:** edit `index.html`
