# The Skin Edit — by Empress Beauty Box

Coming-soon website for **The Skin Edit**: 100% authentic Korean and Canadian skincare,
launching in Pakistan for the first time. Brought to you by Empress Beauty Box, Canada.

## Sections
- Scrolling announcement bar and a Sephora-style striped header
- Hero ("Coming Soon · First Time in Pakistan")
- Trust strip: first time in Pakistan, 100% authentic, Canadian sellers, direct from Korea
- The series: Brightening & Glowing, Glass Skin, Hydrating, Anti-Aging, Acne Care, Sunscreen, Dry Skin
- Our story, lookbook, and the launch-list sign-up

## Run it
No build step. Open `index.html` in a browser, or run `python3 -m http.server 8000`.

## Customize
- **Colors and fonts:** variables at the top of `css/styles.css`
- **Logo:** `images/logo.png` (dark) and `images/logo-light.png` (for dark backgrounds),
  cut from `images/brand-board.jpg`
- **Launch-list form:** shows a thank-you message but does **not** save sign-ups yet.
  Connect a service such as Formspree or Mailchimp in `js/script.js` before launch.
